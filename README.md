# 🚀 DOM_PROJECT_JS_1

### Interactive JavaScript DOM Projects

A collection of hands-on projects built with **HTML5, CSS3, and JavaScript** to strengthen my understanding of DOM manipulation, event handling, dynamic element creation, and interactive UI development.

This repository contains three projects, each focusing on different JavaScript concepts and real-world DOM operations.

---

## 📂 Projects

### 🎨 1. Unlimited Colors

A dynamic background color generator that continuously changes the webpage's background to randomly generated HEX colors.

**✨ Features**

- 🎲 Generates random six-digit HEX color codes.
- ▶️ Starts automatic background color changes with the Start button.
- ⏱️ Changes the background color every second.
- ⏹️ Stops color changes with the Stop button.
- 🛡️ Prevents multiple intervals from starting simultaneously.

**🧠 Concepts Practiced**

- Random number generation using `Math.random()` and `Math.floor()`.
- Generating HEX colors using loops and strings.
- DOM selection and event listeners.
- `setInterval()` and `clearInterval()`.
- Managing interval IDs to control repeated execution.
- Dynamically updating CSS through JavaScript.

**🛠️ Tech Stack:** HTML5 · CSS3 · JavaScript

**📁 Source Code:** [`Unlimited_Colors/`](./Unlimited_Colors/)

**🚀 Live Demo:** [View Unlimited Colors](https://krishnaydv3214-coder.github.io/BASIC_PROJECT_JS_1/)

### 🌙 2. Dark Mode Toggler

A simple interactive webpage theme switcher that toggles the document body between dark and light appearances using a CSS class.

**✨ Features**

- 🌙 Toggles dark mode on button click.
- ☀️ Switches back to the default appearance.
- 🎨 Uses CSS class manipulation to control the theme.
- 🔄 Updates the button text according to the current theme.

**🧠 Concepts Practiced**

- `document.getElementById()`.
- `addEventListener()` for click events.
- `classList.contains()` to check the current theme.
- `classList.toggle()` to switch themes.
- Conditional statements and DOM text updates.

**🛠️ Tech Stack:** HTML5 · CSS3 · JavaScript

**📁 Source Code:** [`Dark_mode_toggle_js_dom/`](./Dark_mode_toggle_js_dom/)

**🚀 Live Demo:** Coming soon

### 📝 3. Dynamic List Creator

An interactive list management application that allows users to add, edit, and remove list items dynamically without reloading the webpage.

**✨ Features**

- ➕ Adds new list items from user input.
- 🚫 Prevents adding items when the input contains only whitespace.
- 🗑️ Removes individual list items using a Remove button.
- ✏️ Enables inline editing by double-clicking a list item.
- 💾 Saves edited text using a Save button.
- 🔄 Replaces existing text with updated content directly in the DOM.
- 🧹 Clears the input field after successfully adding an item.
- ⚡ Creates and updates elements dynamically without reloading the page.

**🧠 Concepts Practiced**

- DOM selection using `getElementById()`.
- Dynamic element creation using `createElement()`.
- Creating text nodes using `createTextNode()`.
- Event handling with `addEventListener()`.
- Input validation using `trim()`.
- DOM insertion using `appendChild()` and `insertBefore()`.
- DOM replacement using `replaceWith()`.
- DOM removal using `remove()`.
- CSS class manipulation using `classList.add()`, `classList.contains()`, and `classList.remove()`.
- Handling multiple events on dynamically created elements.
- Managing editing states with CSS classes.

**🛠️ Tech Stack:** HTML5 · CSS3 · JavaScript

**📁 Source Code:** [`Dynamic_list_creator_js_dom/`](./Dynamic_list_creator_js_dom/)
